¿Qué es ChepiCare Mobile?

Aplicación móvil Android (Expo / React Native) para una clínica veterinaria a domicilio. Sirve a tres audiencias desde una sola app: el público (sin sesión), el dueño de mascotas y el staff clínico. Toda pantalla consume datos reales del backend Rails open-chepicare-web a través de su servicio de dominio — sin datos mockeados.

Instalación rápida

ℹ️
Requisitos: Node ≥ 20, Yarn 4 (Corepack), y para Android un emulador o dispositivo con Expo Go. El backend open-chepicare-web debe estar corriendo (por defecto en http://localhost:3000).
# 1) Dependencias
corepack enable
pnpm install

# 2) Backend en marcha (repo ../open-chepicare-web) en el puerto 3000
#    El emulador Android lo alcanza vía http://10.0.2.2:3000 (default de dev).

# 3) Arrancar Metro / Expo
pnpm start           # luego abre en Expo Go o el dev client

# 4) Compuertas de calidad
pnpm typecheck
pnpm lint
pnpm test            # tests de INTEGRACIÓN reales contra localhost:3000

La URL del backend se puede cambiar en tiempo de ejecución desde la pantalla Configurar servidor (ver Configuración de servidor), sin recompilar.
