Capas de Arquitectura
1
Navegacion
React Navigation — decide que pantalla mostrar. RootNavigator bifurca entre AuthStack y MainTabs segun el estado de autenticacion.
src/navigation/
↕
2
Screens
Pantallas completas. Cada una orquesta la logica de la vista: fetching, estado local e interacciones del usuario.
src/screens/
↕
3
Components
Piezas reutilizables de UI: Button, Card, Input, Badge, Avatar. Consumen tokens del theme para mantener consistencia visual.
src/components/
↕
4
Theme
Design tokens: paletas light/dark, tipografia, spacing, radios, sombras y constantes de layout. Fuente unica de verdad visual.
src/theme/tokens.ts
↕
5
Services
Capa de comunicacion HTTP con el backend Rails. Cliente base + modulos por dominio (auth, pets, appointments).
src/services/
↕
6
Hooks & Utils
Custom hooks (useAuth, useTheme) y funciones utilitarias (storage, formateo). Logica reutilizable desacoplada de la UI.
src/hooks/ · src/utils/

Convenciones
Archivos
PascalCase para componentes (Button.tsx), camelCase para utilidades (format.ts)
Exports
Named exports preferidos. Default export solo para screens (lazy loading).
Estilos
StyleSheet.create() al final del archivo, consumiendo tokens del theme.
Tipos
Interfaces para objetos, types para unions y utilidades.
